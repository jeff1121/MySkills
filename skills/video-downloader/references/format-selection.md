# 格式選擇參考（yt-dlp）

## 基本觀念
- `-f` 用來挑選格式，常用為「最佳影像 + 最佳音訊」。
- `-F` 可列出可用格式，實際能選的以清單為準。
- 建議先用通用範例，再視平台調整。

## 常用範例
- 最佳畫質（建議）
  ```bash
  -f "bv*+ba/b"
  ```
- 限制高度（例如 1080p）
  ```bash
  -f "bv*[height<=1080]+ba/b[height<=1080]"
  ```
- 優先 mp4（可用於相容性較高的環境）
  ```bash
  -f "bv*[ext=mp4]+ba[ext=m4a]/b[ext=mp4]"
  ```
- 僅音訊
  ```bash
  -f "ba" -x --audio-format mp3
  ```

## 進階排序（可選）
- 依解析度、編碼排序：
  ```bash
  -S "res,codec,br"
  ```

## 常見問題
- 若選擇的格式不存在，先 `-F` 確認可用選項。
- 平台差異很大，盡量避免寫死特定 format id。
