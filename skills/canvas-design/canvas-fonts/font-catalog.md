# Canvas Fonts 字型目錄

所有字型皆採用 **SIL Open Font License 1.1** 授權（見各字型的 `*-OFL.txt`）。

> **注意**：本目錄僅包含拉丁語系字型。CJK（中日韓）文字需使用系統字型或額外下載。

---

## Serif（襯線）

適合正文、引用、優雅標題。

| 字型 | 可用字重 | 風格建議 |
|------|----------|----------|
| CrimsonPro | Regular, Bold, Italic | 古典書籍排版、優雅內文 |
| Gloock | Regular | 粗重襯線、適合戲劇性標題 |
| IBMPlexSerif | Regular, Bold, Italic, BoldItalic | 現代襯線、技術文件與藝術並用 |
| InstrumentSerif | Regular, Italic | 精緻細膩、適合極簡設計的點綴 |
| Italiana | Regular | 高對比、時尚感、適合大型標題 |
| LibreBaskerville | Regular | 傳統書籍風格、穩重可靠 |
| Lora | Regular, Bold, Italic, BoldItalic | 平衡的書法感、適合長篇閱讀 |
| YoungSerif | Regular | 厚實溫暖、現代復古感 |
